# 业务日志统一查询补充说明

> 本文档是《全文搜索与运行日志查询实施方案》的补充，说明**新增**业务日志（登录/审计/API调用）统一查询功能的实现。

***

## 一、需求背景

原方案仅实现运行日志查询（Loki），用户要求：

1. **新增业务日志统一查询功能**：在一个页面中查询登录日志、审计日志、API调用日志
2. **新增后端接口**：提供统一的业务日志查询 API
3. **新增前端页面**：实现业务日志查询界面
4. **与运行日志整合**：在统一日志查询页面中，通过 tab 切换运行日志和业务日志

**关键点**：

- 现有系统已有独立的登录日志、审计日志、API调用日志查询页面（保持不变）

- 本次新增的是**统一查询入口**，数据来源仍是 MySQL 现有日志表

- 新增的统一接口与现有独立接口**并存**，互不影响

***

## 二、架构调整

### 2.1 数据源分离

| 日志类型        | 存储    | 用途           | 查询方式               | 保留期 |
| ----------- | ----- | ------------ | ------------------ | --- |
| **运行日志**    | Loki  | 排障、性能分析、异常追踪 | LogQL、时间+级别+关键词    | 7天  |
| **登录日志**    | MySQL | 安全审计、登录统计    | SQL、用户名+IP+状态      | 永久  |
| **审计日志**    | MySQL | 合规审计、操作追溯    | SQL、模块+操作+用户       | 永久  |
| **API调用日志** | MySQL | 外部集成监控、计费依据  | SQL、服务名+状态+traceId | 永久  |

### 2.2 统一查询架构

```
管理后台 → 统一日志查询页面
              ├─ Tab 1: 运行日志
              │    ↓
              │  后端 UnifiedLogHandler::queryRuntimeLogs
              │    ↓
              │  RuntimeLogQueryService → Loki Adapter → Loki
              │
              └─ Tab 2: 业务日志
                   ↓
                 后端 UnifiedLogHandler::queryBusinessLogs
                   ↓
                 UnifiedLogQueryService → LoginLogQueryService/AuditLogQueryService/ApiCallLogQueryService → MySQL
```

## 三、后端实施清单

### 3.1 Application 层 - 统一日志查询服务

**文件（新建）**：`apex-application/src/main/java/com/apex/scaffold/application/service/UnifiedLogQueryService.java`

**功能**：聚合运行日志（Loki）和业务日志（MySQL），提供统一查询接口

**核心方法**：

```java
/**
 * 查询业务日志（登录/审计/API调用）
 * 
 * @param logType 日志类型：login/audit/api-call
 * @param keyword 关键词
 * @param startTime 开始时间
 * @param endTime 结束时间
 * @param pageNum 页码
 * @param pageSize 每页大小
 * @return 分页业务日志
 */
Mono<PageResponse<UnifiedLogQueryDTO>> queryBusinessLogs(
        String logType,
        String keyword,
        String startTime,
        String endTime,
        int pageNum,
        int pageSize);
```

**实现要点**：

- 根据 `logType` 路由到对应 Service：

  - `login` → `LoginLogQueryService`

  - `audit` → `AuditLogQueryService`

  - `api-call` → `ApiCallLogQueryService`

- 将不同类型日志转换为统一 DTO

### 3.2 Interfaces 层 - 统一日志查询 Handler

**文件（新建）**：`apex-interfaces/src/main/java/com/apex/scaffold/interfaces/handler/UnifiedLogHandler.java`

**功能**：HTTP 端点，支持运行日志和业务日志查询

**核心端点**：

1. `GET /admin-api/v1/logs/runtime` - 查询运行日志（Loki）

   - 参数：level、keyword、traceId、startTime、endTime、limit

   - 权限：`system:log:query`

2. `GET /admin-api/v1/logs/business` - 查询业务日志（MySQL）

   - 参数：type（login/audit/api-call）、keyword、startTime、endTime、page、size

   - 权限：`system:log:query`

3. `GET /admin-api/v1/logs/grafana-url` - 获取 Grafana Explore 跳转链接

   - 权限：`system:log:grafana`

### 3.3 Router 注册

**文件**：`apex-interfaces/src/main/java/com/apex/scaffold/interfaces/router/ApiRouter.java`

**变更**：

```java
@Bean
public RouterFunction<ServerResponse> unifiedLogRoutes(UnifiedLogHandler handler) {
    return RouterFunctions.route()
            .GET("/admin-api/v1/logs/runtime", handler::queryRuntimeLogs)
            .GET("/admin-api/v1/logs/business", handler::queryBusinessLogs)
            .GET("/admin-api/v1/logs/grafana-url", handler::getGrafanaExploreUrl)
            .build();
}
```

## 四、前端实施清单

### 4.1 API 封装

**文件（新建）**：`apex-admin-web/src/api/unifiedLog.ts`

**功能**：封装统一日志查询 API

**核心接口**：

```typescript
// 运行日志查询
export interface RuntimeLogQuery {
  level?: string
  keyword?: string
  traceId?: string
  startTime: string
  endTime: string
  limit?: number
}

export function queryRuntimeLogs(params: RuntimeLogQuery): Promise<RuntimeLogResult>

// 业务日志查询
export interface BusinessLogQuery extends PageQuery {
  type: 'login' | 'audit' | 'api-call'
  keyword?: string
  startTime?: string
  endTime?: string
}

export function queryBusinessLogs(params: BusinessLogQuery): Promise<PageResponse<BusinessLog>>

// Grafana 跳转
export function getGrafanaExploreUrl(): Promise<{ url: string }>
```

### 4.2 统一日志查询页面

**文件（新建）**：`apex-admin-web/src/views/monitor/unified-log/index.vue`

**功能**：统一日志查询页面，包含运行日志和业务日志两个 tab

**页面结构**：

```
<el-tabs v-model="activeTab">
  <!-- Tab 1: 运行日志（Loki） -->
  <el-tab-pane label="运行日志" name="runtime">
    <查询表单>
      - 日志级别（info/warn/error）
      - 关键词
      - TraceID
      - 时间范围（快捷选择：15分钟/1小时/6小时/24小时）
      - 操作按钮：查询、重置、Grafana高级查询
    </查询表单>
    
    <日志表格>
      - 时间、级别、日志内容、TraceID、Logger
      - 最多展示1000条
      - 提示：如超限，引导使用 Grafana
    </日志表格>
  </el-tab-pane>
  
  <!-- Tab 2: 业务日志（MySQL） -->
  <el-tab-pane label="业务日志" name="business">
    <查询表单>
      - 日志类型（审计日志/登录日志/API调用日志）
      - 关键词
      - 时间范围
      - 操作按钮：查询、重置
    </查询表单>
    
    <日志表格>
      - 时间、用户、模块、操作、描述、状态、IP
      - 支持分页（20/50/100条每页）
    </日志表格>
  </el-tab-pane>
</el-tabs>
```

**特性**：

- 首次加载默认显示运行日志 tab，默认查询最近1小时

- 切换 tab 时自动加载对应日志（懒加载）

- 运行日志提供 Grafana 跳转按钮

- 业务日志支持类型切换、分页

- 统一错误处理和 Loading 状态

## 五、验收标准补充

### 5.1 功能验收

- [ ] **业务日志查询**：选择"审计日志"，输入用户名关键词，返回符合条件的审计日志

- [ ] **类型切换**：切换"登录日志"、"API调用日志"，表格展示对应数据

- [ ] **分页**：业务日志超过20条，分页正常工作

- [ ] **Tab切换**：首次点击"业务日志" tab，自动加载数据

- [ ] **Grafana跳转**：运行日志 tab 点击"Grafana高级查询"，新窗口打开 Grafana Explore

### 5.2 权限验收

- [ ] **统一权限**：拥有 `system:log:query` 权限的用户可同时访问运行日志和业务日志

- [ ] **权限拒绝**：无权限用户访问 `/admin-api/v1/logs/runtime` 或 `/admin-api/v1/logs/business` 返回 403

### 5.3 前端体验验收

- [ ] **默认行为**：页面加载后自动显示运行日志 tab，默认查询最近1小时

- [ ] **Loading状态**：查询时显示加载动画，禁用查询按钮

- [ ] **错误提示**：查询失败时展示 ElMessage 错误提示

- [ ] **空数据提示**：无日志时表格显示"暂无数据"

## 七、关键差异对比

| 维度     | 原方案                          | 补充后方案                                           |
| ------ | ---------------------------- | ----------------------------------------------- |
| 运行日志查询 | ✅ Loki（应用 stdout/文件日志）       | ✅ Loki（应用 stdout/文件日志）                          |
| 业务日志查询 | ❌ 无统一入口                      | ✅ MySQL（登录/审计/API调用）                            |
| 前端页面   | 单一运行日志页面                     | 统一页面（双 tab）                                     |
| 后端端点   | `/admin-api/v1/runtime-logs` | `/admin-api/v1/logs/runtime` + `/logs/business` |
| 菜单     | `monitor/runtime-log`        | `monitor/unified-log`                           |
| 权限     | `system:runtime-log:query`   | `system:log:query`（统一）                          |
| 用户体验   | 需跳转多个菜单查看不同日志                | 一个页面切换 tab 查看所有日志                               |
