## 🔧 技术细节

### 核心技术栈

```javascript
// Mermaid 配置
mermaid.initialize({
    startOnLoad: false,
    theme: 'base',
    themeVariables: {
        primaryColor: '#667eea',      // 项目主色
        primaryTextColor: '#1e293b',
        primaryBorderColor: '#4f46e5',
        lineColor: '#64748b',
        secondaryColor: '#f1f5f9',
        tertiaryColor: '#f8fafc'
    }
});
```

### 文档加载流程

```
用户选择文档
    ↓
异步 fetch 请求
    ↓
解析 Markdown 内容
    ↓
提取 Mermaid 代码块
    ↓
转换为 HTML (Marked)
    ↓
渲染 Mermaid 图表
    ↓
显示到页面
```
