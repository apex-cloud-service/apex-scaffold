**步骤1**: 加载公共函数库

```bash

source "${SCRIPT_DIR}/lib/common.sh"
```

**步骤2**: 获取项目根目录

```bash

```

**步骤3**: 使用公共函数

```bash
# 文件查找
java_files=$(safe_find "apex-*/src/main/java" "*.java")

# 计数统计
count=$(safe_count "@author" "$file")

# 数字比较

```

### 5.2 如何迁移现有脚本

**步骤1**: 备份原脚本

```bash
cp script.sh script.sh.backup
```

**步骤2**: 添加库引用

```bash

source "${SCRIPT_DIR}/../lib/common.sh"  # 根据脚本位置调整路径
```

**步骤3**: 替换函数调用

| 原代码 | 替换为 |
|--------|--------|
| `find ... -not -path ...` | `safe_find` |
| `grep -c ... \| tr -d '\n'` | `safe_count` |
| `[ "$a" -gt "$b" ]` | `safe_gt "$a" "$b"` |
| `echo "✓ ..."`或`echo "✗ ..."` | `log_success` / `log_failure` |
| 硬编码路径 | `get_project_root` |

**步骤4**: 测试验证

```bash

```
