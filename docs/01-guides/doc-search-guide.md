# 文档搜索工具使用说明

## 📖 功能介绍

文档搜索工具是一个基于浏览器的客户端搜索系统,帮助您快速查找 Apex Scaffold 项目的技术文档。

### ✨ 核心功能

1. **实时搜索** - 输入关键词立即显示搜索结果
2. **分类过滤** - 按文档类型快速筛选(集成、前端、运维、架构、商业化、报告)
3. **关键词高亮** - 搜索结果中的关键词自动高亮显示
4. **智能匹配** - 支持标题、描述、标签、路径多维度匹配
5. **快捷键支持** - 按 `/` 键快速聚焦搜索框
6. **无需服务器** - 纯客户端实现,无需后端支持

---

## 🚀 快速开始

### 访问方式

1. **通过文件**: 直接打开 `docs/doc-search.html` 文件
2. **通过链接**: 在各文档索引页面点击"🔍 文档搜索工具"链接
3. **本地服务器**: 启动项目后访问 `http://localhost:8080/docs/doc-search.html`

### 基本使用

1. **搜索文档**
   - 在搜索框输入关键词(如: "OAuth2", "前端组件", "监控配置")
   - 结果会实时显示在下方

2. **分类过滤**
   - 点击"全部"、"集成"、"前端"等按钮
   - 结果会按选定的分类筛选

3. **查看文档**
   - 点击文档标题即可在新标签页打开文档
   - 文档路径显示在标题下方

## 💡 搜索技巧

### 关键词搜索

支持搜索以下内容:

- **文档标题**: "OAuth2 集成指南"
- **文档描述**: "集成操作指南和最佳实践"
- **标签**: OAuth2, 认证, SSO
- **文件路径**: integration/oauth2/integration-guide.md

### 搜索示例

| 搜索关键词 | 匹配结果 |
|-----------|---------|
| `OAuth2` | 所有包含 OAuth2 的文档 |

   - 输入完整的文档名称
   - 如: "OAuth2 集成指南"

## 📝 常见问题

### Q: 为什么有些文档搜索不到?

A: 文档搜索工具目前包含 80+ 个核心文档索引。如果需要搜索其他文档,可以:
1. 查看完整的文档索引: [ARCHITECTURE_INDEX.md](../02-architecture/architecture-index.md)
2. 查看文档整合摘要: [INTEGRATION_SUMMARY.md](../_archive/INTEGRATION_SUMMARY.md)

### Q: 如何添加新文档到搜索工具?

A: 编辑 `docs/doc-search.html` 文件,在 `documents` 数组中添加新文档对象:

```javascript
{
    title: "文档标题",
    path: "docs/path/to/document.md",
    description: "文档描述",
    category: "integration", // 分类
    tags: ["标签1", "标签2"],
    icon: "🔌" // emoji 图标
}
```

### Q: 搜索工具支持哪些浏览器?

A: 支持所有现代浏览器:
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

### Q: 搜索工具是否需要网络连接?

A: 不需要。文档搜索工具是纯客户端实现,所有数据和逻辑都在浏览器中运行,无需网络连接。
