### 💡 典型使用场景

#### 场景 1: 后端开发

```
1. 点击"后端"分类
2. 浏览 DDD 架构、缓存方案、消息队列等文档
3. 搜索特定技术栈(如 "Redis", "RocketMQ")
```

#### 场景 2: 安全实施

```
1. 点击"安全"分类
2. 查看 JWT 认证、RBAC 权限等安全方案
3. 搜索 "加密" 或 "认证" 关键词
```

#### 场景 3: 测试开发

```
1. 点击"测试"分类
2. 浏览单元测试、集成测试、性能测试指南
3. 搜索 "JUnit" 或 "性能测试"
```

#### 场景 4: 规范查询

```
1. 点击"规范"分类
2. 查看开发规范、API 设计规范
3. 搜索 "RESTful" 或 "OpenAPI"
```

## v1.0 - 2026-09-09 (初始版本)

### 🎉 首次发布

**文档搜索工具** - 为 Apex Scaffold 项目添加强大的文档搜索功能

### ✨ 核心功能

1. **实时搜索** - 输入关键词立即显示结果
2. **分类过滤** - 7 个文档分类快速筛选
3. **关键词高亮** - 搜索结果自动高亮
4. **智能匹配** - 多维度模糊匹配
5. **快捷键支持** - 按 `/` 键快速聚焦
6. **响应式设计** - 支持桌面和移动端
