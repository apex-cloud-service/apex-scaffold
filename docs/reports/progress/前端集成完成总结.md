## ⚠️ 已知问题

### TypeScript 编译错误
**状态**：非阻塞（不影响功能运行）

**错误类型**：
1. `tsconfig.json` 的 `lib` 配置缺少 ES2015+（导致 Map/Set/Promise 等类型未定义）
2. `src/api/workflow.ts` 存在类型兼容性问题（与本次集成无关）
3. `src/views/workflow/components/TaskActions.vue` 缺少 `listUsers` 导入（与本次集成无关）

**解决方案**：
```json
// tsconfig.json 建议修改
{
  "compilerOptions": {
    "lib": ["ES2015", "DOM", "DOM.Iterable"],
    "target": "ES2015",
    "esModuleInterop": true
  }
}
```

**影响范围**：
- ❌ `npm run build` 会报错退出
- ✅ `npm run dev` 可正常运行（Vite 使用 esbuild，不执行 TypeScript 检查）
- ✅ 浏览器运行正常（现代浏览器支持 ES2015+）
