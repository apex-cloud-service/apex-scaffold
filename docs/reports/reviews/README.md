### 上线阻断问题清单

以下9个问题必须在生产上线前完成修复：

#### 🔴 P0 - 严重问题 (5个)

1. **问题1**: Token明文存储  
   - **风险**: 数据库泄露导致所有Token泄露
   - **工期**: 2天
   - **文件**: `V25__oauth2_authorization_server_schema.sql`, `TokenServiceImpl.java`

2. **问题3**: Refresh Token轮换机制缺失  
   - **风险**: Token泄露后无法及时发现
   - **工期**: 3天
   - **文件**: `TokenServiceImpl.java`

3. **问题6**: JWT密钥管理无轮换机制  
   - **风险**: 密钥泄露后无法快速响应
   - **工期**: 2天
   - **文件**: `JwtKeyRotationService.java` (新增)

4. **问题12**: 审计日志不完整  
   - **风险**: 安全事件无法追溯
   - **工期**: 2天
   - **文件**: `UnifiedAuditService.java` (新增)

5. **问题14**: 敏感配置硬编码  
   - **风险**: 配置泄露导致系统被入侵
   - **工期**: 1天
   - **文件**: `application.yml`, 各配置类

#### 🟠 P1 - 高危问题 (4个)

6. **问题4**: OAuth2客户端密钥轮换缺失  
   - **风险**: 客户端密钥泄露后永久有效
   - **工期**: 3天

7. **问题15**: SSO配置明文存储  
   - **风险**: IdP证书和Client Secret泄露
   - **工期**: 2天

8. **问题17**: SAML重放攻击防护缺失  
   - **风险**: 攻击者可重放捕获的SAMLResponse
   - **工期**: 2天

9. **问题18**: OIDC State验证缺失  
   - **风险**: CSRF攻击风险
   - **工期**: 1天

**P0+P1总工期**: 18天（关键路径）
