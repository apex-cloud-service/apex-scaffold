## 维护约定

- 新增工作区治理类交付物请存放于本目录，并以文档标题命名子目录（多格式同名同目录）。
- 系统卡顿诊断的待确认项处理完毕后，如无长期参考价值，可按《工作区管理规范》4.2 归档判定规则移入 `docs/_archive/`。
- 本目录文件多数为机器本地审计/诊断记录，默认不纳入版本控制；如需入库请先确认内容不含密钥、凭据等敏感信息。
