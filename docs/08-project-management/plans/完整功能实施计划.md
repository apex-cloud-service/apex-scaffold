## 四、验收标准

### 4.1 功能验收

#### 全文搜索
- [ ] 能够搜索用户、角色、菜单、部门、字典、配置
- [ ] 搜索结果按相关性排序
- [ ] 关键词高亮显示
- [ ] 支持资源类型过滤
- [ ] 支持分页
- [ ] 租户隔离生效
- [ ] 创建/修改/删除资源后索引自动更新
- [ ] 定时校准任务每天自动执行
- [ ] 管理员能手动触发索引重建

#### 运行时日志查询
- [ ] 能够根据时间范围查询运行时日志
- [ ] 能够按日志级别过滤
- [ ] 能够按 traceId 搜索
- [ ] 能够按关键词搜索
- [ ] 日志解析正确（时间、级别、消息、traceId）
- [ ] 管理后台界面能够查询和展示日志

#### 业务日志统一查询
- [ ] 能够通过统一接口查询审计日志
- [ ] 能够通过统一接口查询登录日志
- [ ] 能够通过统一接口查询 API 调用日志
- [ ] 前端双 tab 展示运行时日志和业务日志

### 4.2 性能验收

- [ ] 搜索响应时间 P95 < 200ms
- [ ] 运行时日志查询响应时间 P95 < 2s
- [ ] 索引同步延迟 < 5s（P95）
- [ ] Meilisearch 内存占用 < 1GB（1 万条索引）
- [ ] Loki 存储占用 < 2GB（7 天日志，中等流量）

### 4.3 稳定性验收

- [ ] Meilisearch 不可用时搜索降级返回空结果，不影响业务
- [ ] Loki 不可用时运行时日志查询降级返回空结果
- [ ] 索引同步失败不影响业务操作
- [ ] 定时校准任务失败不影响应用稳定性
- [ ] 应用重启后索引状态正确

### 4.4 安全验收

- [ ] 租户隔离生效（租户 A 无法搜索租户 B 的数据）
- [ ] 权限控制生效（无权限用户无法访问搜索和日志 API）
- [ ] 敏感字段脱敏（邮箱、手机号在索引中脱敏）
- [ ] 运行时日志不包含密码、密钥等敏感信息
- [ ] API 调用日志查询参数脱敏

## 五、风险与应对

### 5.1 技术风险

| 风险 | 影响 | 概率 | 应对措施 |
|-----|------|------|---------|

## 七、关键决策记录

| 决策点 | 选项 | 选择 | 理由 |
|-------|------|------|------|
| 搜索引擎 | Elasticsearch vs Meilisearch | Meilisearch | 轻量、CJK 支持好、部署简单 |
| 日志聚合 | ELK vs Loki | Loki | 比 ELK 轻量 10 倍、与 Grafana 集成 |
| 业务日志存储 | MySQL vs Loki | MySQL | 审计日志需事务一致性、复杂查询 |
| 索引同步机制 | 定时轮询 vs 事件驱动 | 事件驱动 | 实时性好、资源占用低 |
| 前端查询界面 | 独立页面 vs 统一入口 | 统一入口（双 tab） | 用户体验更好 |
| 日志采集器 | Logstash vs Alloy | Alloy | 官方推荐、配置简单、支持多协议 |
