```java
/**
 * Redisson 客户端配置类
 *
 * <p>显式配置 Redisson 分布式锁的 Watchdog（看门狗）机制和连接池参数，
 * 提升 Redis 操作的可控性和可观测性。
 *
 * <h2>Watchdog 机制说明</h2>
 * <ul>
 *   <li><strong>Lock Watchdog Timeout</strong>：默认 30 秒，看门狗续期间隔为该值的 1/3（即 10 秒）</li>
 *   <li><strong>自动续期</strong>：持有锁的线程会每隔 10 秒自动续期，直到业务执行完毕或进程崩溃</li>
 *   <li><strong>适用场景</strong>：执行时间不确定的分布式任务，防止锁提前释放</li>
 * </ul>
 *
 * <h2>配置项说明</h2>
 * <ul>
 *   <li>{@code apex.redis.lock-watchdog-timeout}: 看门狗超时时间（毫秒），默认 30000</li>
 *   <li>{@code apex.redis.command-timeout}: Redis 命令超时时间（毫秒），默认 3000</li>
 *   <li>{@code apex.redis.retry-attempts}: 命令重试次数，默认 3</li>
 *   <li>{@code apex.redis.retry-interval}: 重试间隔（毫秒），默认 1500</li>
 * </ul>
 *
 * @author Apex Team
 * @version 1.0.0
 * @since 1.4.0
 * @see org.redisson.config.Config
 * @see org.redisson.api.RedissonClient
 */
```

**实现要点**:
- 读取配置项 `apex.redis.lock-watchdog-timeout`（默认 30000ms）
- 配置命令超时、重试次数、重试间隔
- 配置连接池参数（最小空闲连接、最大连接数、连接超时）
- 添加配置日志输出，便于排查问题

#### 1.2 创建配置属性类

**文件**: `apex-common/src/main/java/com/apex/scaffold/common/config/RedissonProperties.java`

**内容**:
```java
/**
 * Redisson 配置属性类
 *
 * <p>定义 Redisson 客户端的配置参数，支持通过 {@code apex.redis.*} 配置项覆盖。
 *
 * @author Apex Team
 * @version 1.0.0
 * @since 1.4.0
 */
@Data
@ConfigurationProperties(prefix = "apex.redis")
public class RedissonProperties {
    /**
     * 分布式锁看门狗超时时间（毫秒）
     * 
     * <p>默认 30000ms（30 秒），看门狗会每隔该值的 1/3 自动续期。
     */
    private long lockWatchdogTimeout = 30000L;

    /**
     * Redis 命令超时时间（毫秒）
     * 
     * <p>默认 3000ms（3 秒），超过该时间未响应则抛出超时异常。
     */
    private int commandTimeout = 3000;

    /**
     * 命令失败重试次数
     * 
     * <p>默认 3 次，仅对网络瞬时故障有效。
     */
    private int retryAttempts = 3;

    /**
     * 重试间隔（毫秒）
     * 
     * <p>默认 1500ms，每次重试前等待的时间。
     */
    private int retryInterval = 1500;
}
```

/**
 * 工作流定义聚合根
 *
 * <p>表示一个完整的业务流程定义，包含流程节点（审批、条件、开始、结束）
 * 和节点间的流转边。支持多种审批策略（或签/会签）和审批人类型（指定用户/角色/上级/发起人）。
 *
 * <h2>领域模型设计</h2>

 * // 创建请假审批流程
 * WorkflowDefinitionAggregate definition = WorkflowDefinitionAggregate.builder()

 *     .addNode(WorkflowNode.start("node_1", "开始"))
 *     .addNode(WorkflowNode.approval("node_2", "部门主管审批")
 *         .approverType(ApproverType.SUPERIOR)
 *         .approvalStrategy(ApprovalStrategy.OR))
 *     .addNode(WorkflowNode.end("node_3", "结束"))
 *     .addEdge(WorkflowEdge.of("edge_1", "node_1", "node_2"))
 *     .addEdge(WorkflowEdge.of("edge_2", "node_2", "node_3"))
 *     .build();
 *     
 * // 验证流程定义
 * definition.validate();
 * }</pre>

 * @version 1.3.0
 * @since 1.3.0
 * @see WorkflowNode
 * @see WorkflowEdge
 * @see ProcessInstanceEntity
 */
