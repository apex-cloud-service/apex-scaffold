### 1.1 项目基本信息

**项目名称**: Apex Scaffold  
**版本**: v1.2.0  
**仓库路径**: `/Users/work/apex-scaffold`

### 1.2 后端项目特征

**技术栈**:
- Java 17 (LTS)
- Spring Boot 3.5.15
- Spring WebFlux 6.x（响应式编程）
- Project Reactor 3.x (Mono/Flux)
- MyBatis-Plus 3.5.10.1
- MySQL 8.0 + Flyway 10.15.0
- Redis 7.x + Redisson 3.36.0
- Nacos 2.x + Sentinel 1.8.x + RocketMQ 2.3.3
- JWT 认证 + RBAC 权限

**架构模式**: DDD 四层架构
- `apex-interfaces` - 接口层（Handler + RouterFunction）
- `apex-application` - 应用层（Service + DTO + Assembler）
- `apex-domain` - 领域层（Entity + Repository接口 + 领域服务）
- `apex-infrastructure` - 基础设施层（持久化实现 + 外部服务）

**代码规范工具**:
- Lombok 1.18.36 (lombok.config)
- Spotless 2.43.0 (Palantir Java Format)
- Maven PMD Plugin + 阿里P3C规则
- JaCoCo (覆盖率 >= 60%)
- MapStruct 1.5.5.Final

**核心规范**:
- 统一响应格式 `Result<T>`
- 响应式编程 Mono/Flux
- 函数式路由 RouterFunction
- AOP 切面（操作日志、权限校验、限流熔断）
- 多租户 tenant_id 隔离

### 1.3 前端项目特征

**独立前端项目**: `apex-admin-web` (不在当前仓库)  
**技术栈** (基于文档推断):
- Vue 3.5.13 (Composition API)
- Vite 6.0.7
- TypeScript 5.x
- Element Plus 2.x
- Pinia 2.x
- Vue Router 4.x
- Axios 1.x
- ECharts (数据可视化)

**架构模式**:
- 动态路由（后端菜单树驱动）
- Pinia 状态管理
- API 接口统一封装
- 权限控制（按钮级）
