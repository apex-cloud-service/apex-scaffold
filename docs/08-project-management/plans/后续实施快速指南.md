**错误1：SearchResult类型转换**
```java

// 可能的修复
Searchable searchable = index.search(request);
SearchResult result = (SearchResult) searchable;

```

**错误2：批量索引方法参数**
```java

```

```java
// UnifiedSearchHandler.java
@Component
@RequiredArgsConstructor
public class UnifiedSearchHandler {
    private final SearchService searchService;
    
    @RequirePermission("system:search:query")
    @OperationLog(module = "全文搜索", type = OperationLog.OperationType.SELECT)
    public Mono<ServerResponse> search(ServerRequest request) {
        String keyword = request.queryParam("keyword").orElse("");
        String types = request.queryParam("types").orElse("");
        int page = parseInt(request.queryParam("page").orElse("1"));
        int size = parseInt(request.queryParam("size").orElse("20"));
        
        Set<String> resourceTypes = types.isEmpty() ? null : 
            Arrays.stream(types.split(",")).collect(Collectors.toSet());
        
        return searchService.search(keyword, resourceTypes, page, size)
            .flatMap(this::buildSuccess);
    }
}
```

**代码骨架**：
```java
@Component
@RequiredArgsConstructor
public class SearchIndexReconciliationJob {
    private final IndexSyncPort indexSyncPort;
    
    @Scheduled(cron = "0 0 2 * * ?")  // 每天凌晨2点
    public void syncIncremental() {
        long since24Hours = System.currentTimeMillis() - 24 * 3600 * 1000;
        String[] types = {"user", "role", "menu", "dept", "dict", "config"};
        
        for (String type : types) {
            indexSyncPort.syncIncremental(type, since24Hours)
                .doOnSuccess(count -> log.info("Incremental sync: type={}, count={}", type, count))
                .subscribe();
        }
    }
}
```
