# 验收方案

> **版本**: v1.0
> **核对日期**: 2026-10-30
> **基线提交**: `b8e5733`
> **维护者**: Apex Team

本文档定义交付验收的验收项、判定标准、证据要求与准出条件。**离线可验证项**与**在线运行项**分开判定，缺少环境取证的项不得记为通过。

---

## 1. 验收角色与职责

| 角色 | 职责 |
| --- | --- |
| 交付方（技术） | 准备产物、执行离线验证、配合在线验证、提供证据 |
| 交付方（产品） | 确认功能范围与 [需求追踪矩阵](./requirements-traceability.md) 一致 |
| 接收方（客户/运维） | 按清单执行部署与功能验收，签署确认 |
| 质量把关 | 核对证据完整性，确认准出条件 |

---

## 2. 验收维度

| 维度 | 判定依据 | 可离线验证 |
| --- | --- | --- |
| 交付物完整性 | [交付物清单](./deliverables.md) §5 | 是 |
| 构建与测试 | [质量与验证计划](./quality-plan.md) §3 | 是 |
| 功能范围 | [需求追踪矩阵](./requirements-traceability.md) | 是（代码/测试层面） |
| 接口契约 | 路由清单与 OpenAPI 声明一致 | 是 |
| 数据库迁移 | 双库版本一致、空库可执行 | 否（需数据库） |
| 部署与启动 | 服务可启动、健康检查通过 | 否（需环境） |
| 安全配置 | 无默认密钥、无越权访问 | 部分 |
| 运维能力 | 监控、告警、日志、备份可用 | 否（需环境） |
| 授权能力 | License 有效放行、无效降级 | 部分 |

## 4. 在线验收项

以下项目需要 MySQL、Redis、Nacos 或容器/K8s 环境，**必须在目标环境执行并归档输出**。

### 4.1 启动与健康

| # | 验收项 | 判定标准 | 命令 |
| --- | --- | --- | --- |
| D-01 | 数据库初始化 | 各业务域数据库迁移执行成功，`flyway_schema_history` 无失败记录 | 启动日志 |
| D-02 | 服务启动 | 每个服务日志出现 `Started ...Application` | 启动日志 |
| D-03 | 健康检查 | 业务端口健康检查返回 UP | `curl http://<host>:<port>/actuator/health` |
| D-04 | 网关路由 | 各域请求经网关正确转发 | 接口调用 |
| D-05 | 服务发现 | 开启 Nacos 时实例正确注册 | Nacos 控制台 |

### 4.2 认证与权限

| # | 验收项 | 判定标准 |
| --- | --- | --- |
| E-01 | 密码登录 | `POST /auth/v1/login` 返回令牌 |
| E-02 | 令牌刷新 | Refresh Token 可换取新 Access Token |
| E-03 | 登出 | `POST /api/v1/auth/logout` 默认仅当前会话失效；`?scope=all` 时该用户全部会话失效 |
| E-04 | 未认证拦截 | 受保护接口返回 401 |
| E-05 | 权限拦截 | 无权限用户返回统一错误码与 traceId |
| E-06 | 数据权限 | 不同数据范围用户看到的数据集合不同 |

## 5. 判定规则

### 5.1 单项判定

| 判定 | 条件 |
| --- | --- |
| 通过 | 达到判定标准，且有可复核证据 |
| 有条件通过 | 功能可用但存在记录在案的已知限制，客户书面接受 |
| 不通过 | 未达标准，或无法提供证据 |
| 不适用 | 该能力未纳入本版本交付范围 |

### 5.2 准出条件

交付版本放行需同时满足：

1. 离线验收项 A、B、C 全部“通过”。
2. 在线验收项 D、E、F、G 在目标环境执行，“不通过”项为零。
3. [风险登记册](./risk-register.md) 中高等级风险全部关闭或有书面接受记录。
4. [交付物清单](./deliverables.md) §5 完整性校验全部通过。
5. 交付记录包含版本、提交、构建环境、测试统计与校验和。

### 5.3 不得作为通过依据的情形

- 仅编译通过，未运行测试。
- `-DskipTests` 打包。
- 缺少环境导致测试跳过，却记为通过。
- 只有文档描述，没有可执行入口或测试证据。
- 在未提交的工作区上验证，交付基线却是另一提交。
