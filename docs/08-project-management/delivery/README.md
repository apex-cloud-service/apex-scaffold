## 与既有文档的关系

本目录不替代既有文档，而是补充交付管理维度：

- 技术事实以代码、根 [pom.xml](../../../pom.xml)、各服务 `application*.yml` 与迁移脚本为准；本文档只引用，不复制。
- [销售交付清单](../../07-commercial/sales/DELIVERY_CHECKLIST.md) 与 [旧项目交付清单](../../03-api/project-delivery-checklist.md) 的模块数、JDK 版本、文档篇数、测试基线已过期，仅作历史记录；交付核对以本目录为准（见 [风险登记册](./risk-register.md) R-09）。
- 微服务迁移验收记录见 [微服务验收清单](../checklists/microservice-acceptance-checklist.md)，其在线验证项与本文档的准出条件相互引用。
- 需求条目原文见 [功能增强需求方案](../function-enhancement-requirements.md)，本文档只维护追踪关系，不重复需求正文。
- 文档组织规则见 [文档与脚本目录结构规范](../DOCS_STRUCTURE_STANDARD.md)。

## 使用约定

1. **状态口径**：`已完成` 表示仓库内存在实现与可复核证据；`待验证` 表示实现存在但缺少运行环境取证；`未实现` 表示仓库中不存在对应能力，不得写入已交付范围。
2. **证据口径**：只登记可以被他人重复核对的位置（源码路径、脚本、测试类、文档章节、命令）。命令行输出片段仅在文中有归档说明时可作为证据。
3. **时间口径**：文档中的日期为实际核对日期，不表示功能上线或客户验收日期。
4. **变更口径**：任何交付范围的增减先更新 [交付范围与基线](./delivery-scope.md)，再同步本索引与相关章节。
