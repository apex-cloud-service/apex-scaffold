### 2. P0 验收攻坚（10-19 ~ 10-21）

- **共享 Outbox 缺陷修复 2 项**：解决双库方言兼容问题；修复 MySQL 死信重发重试字段未重置缺陷。
- **生产环境修复**：补齐 auth PostgreSQL 生产 R2DBC runtime 依赖。
- **静态资产登记**：完成 **589 条**历史 SQL 类型归类、**136 个**域表静态权威登记，建立升级链等价性证明基线。
- **动态 SQL 验证**：完成 auth 模块 V45、V52、V55 等多批分支覆盖与重放验证。
- **质量回归**：多轮 Java 17 全仓 `clean verify` 全部通过。
- **口径决策**：确认项目全新开发、无历史部署，移除"真实旧部署材料"作为 P0 准出阻塞条件，收敛验收范围。

### 3. 验收工具链 Java 化迁移（10-20 ~ 10-21）

- 部署工具组完成 Java 化，**25 个测试用例全部通过**；CI 校验体系由 37 个 Java 文件承接，归档完整性校验扩展至 **28 项**。
- 累计归档删除 29+ 个 Python 文件，全仓扫描 Python **残留为 0**，CI 流水线无 Python 运行器引用。

### 4. RocketMQ 死信路由缺陷修复（10-24）

- **根因**：DLQ 处理器仅读 `ORIGINAL_TOPIC` 属性，与实测死信消息携带的 `RETRY_TOPIC` 不匹配，导致死信路由失败。
- **修复**：改为按消费者订阅的 DLQ Topic 反向映射 originalTopic，从机制上消除属性依赖。
- **验证**：**21 个回归测试全部通过**；真实自然死信到 Outbox 落库验收列入下周计划。

### 5. Seata 分布式事务测试体系（10-25）

- Ruby 测试脚本**全部替换**为标准 Java 集成测试，纳入 CI 门禁；
- AT / TCC / SAGA / XA 四模式集成测试框架落地，合计 **32 个测试方法**；双库隔离提交/回滚验证进行中。
