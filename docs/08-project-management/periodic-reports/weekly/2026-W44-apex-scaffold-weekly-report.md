## 二、架构定型：单体收敛为 31 模块

1. **共享设施按能力拆分**（`36387487`）。原单一设施库拆为持久化、缓存、消息、远程调用、第三方集成五个独立 JAR，`apex-infrastructure` 降为旧坐标兼容壳、不再承载实现源码，避免一处改动牵动全仓。
2. **业务能力按域独立成库**（`755ec084`）。system、auth、workflow、file、office 各自成库，域模型、仓储端口与适配器同库内聚；共享 domain 仅保留可跨域复用契约，禁止反向依赖具体业务库。
3. **新增运行模块**（`482f3aae`）。网关加五个业务服务运行模块落地，形成「能力库 + 装配壳」结构，服务只做装配与启动，不复制业务实现。
4. **工程配套同步**（`bbd56133`、`0ae99c72`）。构建 POM、CI 流水线、容器镜像、部署与运维脚本、Nacos 与 Sentinel 配置全部随拆分配套调整，协作规范同步修订。
5. **结论**：本周触及全部 31 个模块，说明拆分是贯通式改造而非局部搬迁；后续新增能力的默认落点由「共享库」改为「所属业务库」。

## 三、后端能力补齐

1. **运维体检 O07b**（`0e9dba36`，141 文件）。历史快照、趋势、CSV 导出、保留期清理与 HMAC-SHA256 签名三态校验（有效 / 已被改写 / 无法验证）配套落地，V70 之前的存量快照标记为「无法验证」而非判篡改；补 `ops_health_export_task` 异步导出表，突破同步导出 5000 行上限。
2. **生成器异步链租约语义收口**（`6a4aad7a`）。候选查询补 `attempts < maxAttempts`；进度回写、完成与失败标记全部限定 `locked_by`，进度回写兼作租约心跳、0 行更新即停止处理；认领后按主键重读实体再执行，新增 `LeaseGuard` 在入口、每单元写盘前、历史落库前复检执行权；保留期清理改为「先查主键、后按主键删除」，解除 MySQL 专属语法对 PostgreSQL 部署的阻断。
3. **调度器租户上下文桥接**（`6a4aad7a`）。生成器任务、体检导出、体检保留期三条链路由仅 `contextWrite` 改为 `TenantContext.withTenant(Mono)` 桥接执行线程 ThreadLocal，修复企业档开启租户拦截器后任务表 SQL 被 `DefaultTenantLineHandler` 拒绝的缺陷（该缺陷为方案文档未记录项）。
4. **租户到期纳入写入门禁**（`ce8559ff`）。`TenantEntity` 增加到期断言与 `expired()` 领域行为（null 视为长期有效），到期不改状态机、不清理既有数据，避免误伤历史数据。
5. **文件与办公链路**。文件分片活跃唯一性迁移（V7 双方言）解决并发重传产生重复分片；文件限时只读分享四端点（创建 / 撤销 / 匿名兑换 / 代理下载），令牌仅存 SHA-256 摘要；办公站内信三通道投递与游标增量收件箱，归属校验与深分页规避同步落地。
6. **契约与网关容错**（`9a1000e2`、`55d2ff9d`）。Nacos `workflow-domain` 路由补 `/api/v2/workflow-definitions/**` 并扩展路由契约测试对三配置源的断言；定义图节点 `position` 类型漂移仅降级该字段并告警、`timeoutHours` 容忍 Long/Double，单节点脏数据不再把整张定义图收敛为空。
7. **文件服务静态多密钥验签**（`f7321a89`）。`IdentityRelayAuthenticationFilter` 支持 `jwt-public-keys-base64` 多键配置，解除多实例 / 多签发方场景只能配置单公钥的运维约束。
