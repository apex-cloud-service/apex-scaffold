# 工作月报

> **历史快照**：本文记录某一时点的状态，模块数、端口、路径与类名以当前代码为准，不作为现状依据。

按自然月归档的工作月报，文件名格式为 `YYYY-MM-all-projects-monthly-report.md`。命名、内容要素与数据口径见 [上级 README](../README.md)。

2026-11-03 起为全项目单月报口径：每月一份，覆盖工作区全部项目（约 500 字，按阶段组织、向领导汇报口径），不再按仓库拆分；此前按 `<范围>` 拆分的历史月报保留为存档。月报按「阶段成果」而非按日流水组织，避免与日报内容重复堆叠。

## 生成与补写约定

- **自动生成**：每月最后一天 17:00 由工作区定时任务产出当月月报，落盘为 `.md` 并回写本索引。
- **数据来源**：当月 `git log`、本目录当月的周报与日报、`.workbuddy/knowledge/`。月报的阶段划分应以周报为骨架，不得逐日复述日报。
- **机构差异**：月报只写结论性成果与遗留问题，具体验证证据引用同期周报或日报，不重复粘贴完整输出。
- **补写**：漏报月份按同一格式补齐，插入索引时保持月份升序；无提交的月份写明「无代码变更」及该月工作性质。
- **去重**：同一月份同一范围只保留一份，二次生成直接覆盖。
- 月报为过程性记录，不参与技术文档索引。
