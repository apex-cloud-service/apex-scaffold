# 工作月报

按自然月归档的工作月报，文件名格式为 `YYYY-MM-<范围>-monthly-report.md`。命名、内容要素与数据口径见 [上级 README](../README.md)。

月报按月汇总，组织方式为「阶段成果」而非按日流水，避免与日报内容重复堆叠。

## 生成与补写约定

- **自动生成**：每月最后一天 17:00 由工作区定时任务产出当月月报，落盘为 `.md` 并回写本索引。
- **数据来源**：当月 `git log`、本目录当月的周报与日报、`.workbuddy/knowledge/`。月报的阶段划分应以周报为骨架，不得逐日复述日报。
- **机构差异**：月报只写结论性成果与遗留问题，具体验证证据引用同期周报或日报，不重复粘贴完整输出。
- **补写**：漏报月份按同一格式补齐，插入索引时保持月份升序；无提交的月份写明「无代码变更」及该月工作性质。
- **去重**：同一月份同一范围只保留一份，二次生成直接覆盖。
- 月报为过程性记录，不参与技术文档索引。
