1. **后端 v2 契约对齐与页面补齐**（`8ff718e`，06:27）。新增/改写审批、文件分享、会议室、组织同步、安全、运维健康、图表、租户、个人中心、登录、工作流定义共 11 个页面，同步 `src/api` 下 `file-share`、`generator`、`ip-access-control`、`meeting-room`、`mfa`、`office`、`office-sync-wizard`、`operations`、`password-recovery`、`tenant`、`workflow`、`message` 等封装与 `src/types`，并更新 `router/dynamic.ts` 的视图注册表。**解决的是**后端已上线的 v2 接口（`/api/v2/platform/tenants`、`/api/v2/operations/*`、`/api/v2/workflow-definitions`）在前端无消费方、管理页存在但契约字段对不上的问题。
2. **生成向导页签**（`c9d3088`，13:16）。`system/generator` 页集成模板目录、结构预检、纯渲染预览（含片段）、携带预览令牌与覆盖开关的异步提交、2 秒轮询进度对话框、取消与按产物 ID 下载；`api/generator.ts` 补齐向导与异步任务封装。**解决的是**代码生成器后端已有异步任务链（提交→轮询→列产物→下载）而前端只有同步预览，异步能力对用户不可见的问题。
3. **游标增量收件箱与投递记录**（`c9d3088`）。`api/message.ts` 新增 `afterId`/`limit` 游标收件箱与投递记录封装，`office/message` 页新增「投递记录」抽屉（渠道/状态/送达时间/失败原因）。**解决的是**站内信只能全量拉取、投递失败无排障入口的问题。
4. **两个匿名公开页**（`c9d3088`）。新增 `/share` 文件分享兑换页（token 兑换与代理下载，支持 `?token=` 直达）与 `/password-recovery` 独立密码找回页（三步流程），注册为 public 静态路由。**解决的是**分享链接与密码找回此前必须进入登录态页面、被鉴权拦截器挡住的可用性断点。
5. **运维健康页租户摘要页签**（`c9d3088`）。消费既有 `GET /tenant-health-summary`。**解决的是**该端点已实现但无页面消费，租户侧健康视图不可达。
6. **租户管理页按钮权限绑定**（`c9d3088`）。补齐 `v-permission`（`tenant:create`、`tenant:lifecycle`、`tenant:quota`）。**解决的是**按钮对无权限用户可见导致点击即 403 的体验缺陷。
7. **前端测试补齐**（`c9d3088`）。新增 `generator.test.ts` 7 项、扩展 `message.test.ts` 3 项（游标默认/自定义参数、投递记录路径）。**解决的是**新增 API 封装无测试覆盖。
8. **文档校准与规范条款调整**（`147c0ee`、`d18d99f`、`53d6afc`）。18 份文档按实现现状校准并标注历史快照，`CONTRIBUTING.md` 与 `docs/reference/comment-style.md` 的注释与协作条款放宽至与仓库现状一致，`4b569e2` 后新增文件的注释按新规范整改 7 个文件。**解决的是**文档描述与代码现实脱节、旧规范条款无法被存量代码满足导致评审反复的问题。
