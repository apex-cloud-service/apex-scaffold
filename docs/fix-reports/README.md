# docs/fix-reports（Bug 修复报告 · 专题历史）

## 用途与边界

- 收录：一次性 Bug/编译错误的修复过程记录（历史快照，含"当时现象"）。
- **不收新内容**：新的修复记录写入 [`docs/records/`](../records/README.md)；若修复方案需要评审，写入 [`docs/reviews/`](../reviews/README.md)。
- 判定口径：本文档里的模块数、端口、路径、类名**不作为现状依据**，一律以当前代码为准。
