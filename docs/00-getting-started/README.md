## 🎯 推荐学习路径

### 第一天：环境搭建与启动

1. 阅读 [快速开始指南](./quickstart.md)
2. 配置开发环境（JDK、Maven、IDE）
3. 使用 Basic 档位启动项目
4. 访问 Swagger UI 查看 API

### 第二天：理解架构与示例

1. 阅读 [入门架构指南](./onboarding-guide.md)
2. 阅读 [示例指南](./example-guide.md)
3. 运行示例代码
4. 尝试修改示例代码

### 第三天：深入学习

1. 升级到 Standard 档位
2. 阅读 [开发手册](../01-guides/developer-handbook.md)
3. 使用代码生成器创建新模块
4. 编写单元测试
