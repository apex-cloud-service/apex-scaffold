2. 创建SearchService.java（100行）
```java
@Service
@RequiredArgsConstructor
public class SearchService {
    private final SearchRepository searchRepository;
    
    public Mono<PageResponse<SearchResultDTO>> search(
        String keyword,
        Set<String> resourceTypes,
        int pageNum,
        int pageSize
    ) {
        // 获取当前租户ID和用户ID
        Long tenantId = TenantContext.getTenantId();
        Long userId = SecurityContext.getUserId();
        
        // 调用搜索仓储
        return searchRepository.search(keyword, resourceTypes, tenantId, userId, pageNum, pageSize)
            .map(pageResponse -> {
                List<SearchResultDTO> dtos = pageResponse.getRecords().stream()
                    .map(this::toDTO)
                    .collect(Collectors.toList());
                return PageResponse.of(dtos, pageResponse.getTotal(), pageNum, pageSize);
            });
    }
    
    private SearchResultDTO toDTO(SearchResultEntity entity) {
        return SearchResultDTO.builder()
            .resourceType(entity.getResourceType())
            .resourceId(entity.getResourceId())
            .title(entity.getTitle())
            .subtitle(entity.getSubtitle())
            .description(entity.getDescription())
            .highlightSnippet(entity.getHighlightSnippet())
            .score(entity.getScore())
            .status(entity.getStatus())
            .createdAt(entity.getCreatedAt() != null ? entity.getCreatedAt().toString() : null)
            .updatedAt(entity.getUpdatedAt() != null ? entity.getUpdatedAt().toString() : null)
            .build();
    }
}
```

**第三步：创建Interfaces层（0.5天）**

1. 创建UnifiedSearchHandler.java（150行）
```java
@Component
@RequiredArgsConstructor
public class UnifiedSearchHandler {
    private final SearchService searchService;
    
    @RequirePermission("system:search:query")
    @OperationLog(module = "全文搜索", type = OperationLog.OperationType.SELECT)
    public Mono<ServerResponse> search(ServerRequest request) {
        String keyword = request.queryParam("keyword").orElse("");
        String types = request.queryParam("types").orElse("");
        int page = Integer.parseInt(request.queryParam("page").orElse("1"));
        int size = Integer.parseInt(request.queryParam("size").orElse("20"));
        
        Set<String> resourceTypes = types.isEmpty() ? null : 
            Arrays.stream(types.split(",")).collect(Collectors.toSet());
        
        return searchService.search(keyword, resourceTypes, page, size)
            .flatMap(result -> ServerResponse.ok()
                .contentType(MediaType.APPLICATION_JSON)
                .bodyValue(ResponseResult.success(result)));
    }
}
```

2. 修改ApiRouter.java添加路由

@Bean
public RouterFunction<ServerResponse> unifiedSearchRoutes(UnifiedSearchHandler handler) {
    return RouterFunctions.route()
        .GET("/admin-api/v1/search", handler::search)
        .build();
}
