## 📖 如何使用

### 在线浏览
```bash
# 在浏览器中打开
open reports/project-summary-report/project-summary-report.html
```

### 打印为 PDF
1. 在浏览器中打开报告
2. 按 `Ctrl+P` (Windows) 或 `Cmd+P` (Mac)
3. 选择"另存为 PDF"
4. 建议设置：
   - 纸张大小: A4
   - 边距: 默认
   - 页眉页脚: 关闭

### 导出为 Word
使用浏览器打印功能导出为 PDF 后，可通过以下方式转换为 Word：
- Adobe Acrobat: 文件 → 导出到 → Microsoft Word
- 在线工具: PDF to Word 转换器
- Word: 打开 → 选择 PDF 文件
