## 六、图表创建方法

### 方法 1: 使用 Mermaid（推荐）

**优点**: 
- 纯文本定义，易于版本控制
- 可自动转换为 SVG
- 语法简单，学习成本低

**示例**（用户登录时序图）:
```mermaid
sequenceDiagram
    participant C as Client
    participant G as Gateway
    participant A as Auth Service
    participant J as JWT Service
    participant R as Redis
    participant D as Database
    
    C->>G: POST /api/auth/login
    G->>A: 验证请求
    A->>D: 查询用户
    D-->>A: 返回用户信息
    A->>A: 验证密码
    A->>J: 生成 JWT Token
    J->>R: 缓存 Token
    J-->>A: 返回 Token
    A-->>G: 返回登录响应
    G-->>C: 200 OK + Token
```

### 方法 2: 手工绘制 SVG（适合复杂图表）

**优点**:
- 完全自定义样式
- 符合项目深色系配色
- 包含云原生图标
