## 三、公共函数库改进

用户在迁移过程中对公共函数库进行了以下重要改进:

### 1. 重复加载保护

```bash
if [[ ${_APEX_COMMON_LIB_LOADED:-0} == 1 ]]; then
    return 0
fi
_APEX_COMMON_LIB_LOADED=1
```

**优点**: 避免重复 source 导致的 readonly 变量冲突。

### 2. 严格模式启用

```bash
set -euo pipefail
```

**优点**: 提高脚本可靠性,及时发现错误。

### 3. 路径安全处理

```bash
SCRIPT_DIR="$(CDPATH= cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd -P)"
```

**优点**: 避免 CDPATH 干扰,处理符号链接,支持特殊字符。

### 4. 参数验证强化

```bash
safe_find() {
    if [[ $# != 2 || -z ${1:-} || -z ${2:-} ]]; then
        log_error "safe_find: 缺少必需参数"
        return 1
    fi
    # ...
}
```

**优点**: 在 `set -u` 模式下安全验证参数。

### 5. 临时文件安全

```bash
setup_temp_cleanup() {
    local cleanup_command
    printf -v cleanup_command '%q ' cleanup_temp_files "$@"
    trap "$cleanup_command" EXIT
}
```

**优点**: 安全处理包含空格和特殊字符的文件路径。
