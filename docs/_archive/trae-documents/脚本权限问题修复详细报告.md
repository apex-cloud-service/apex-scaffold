## 一、问题概述

### 1.1 问题描述

项目中多个检查脚本在扫描 Java 源代码文件时，使用 `find` 命令遍历项目目录，但未排除特殊目录（`.trae`、`target`、`.git`、`.idea`），导致以下问题：

1. **权限错误**：访问 `.trae` 等受限目录时产生 "Permission denied" 错误
2. **性能问题**：扫描编译产物目录（target）和版本控制目录（.git）导致脚本运行缓慢
3. **结果不准确**：可能统计到编译产物或临时文件，影响检查结果的准确性
4. **数据格式错误**：部分脚本的数字处理逻辑存在问题，导致比较运算失败

### 1.2 影响范围

受影响的脚本：
- `scripts/dev/check/check-springdoc-annotations.sh` - SpringDoc注解检查
- `scripts/dev/check/scan-javadoc-issues.sh` - JavaDoc问题扫描
- `scripts/dev/check/scan-lombok-issues.sh` - Lombok使用问题扫描
- `scripts/check-commercialization-readiness.sh` - 商业化就绪度检查

影响的功能：
- ✅ 代码质量检查
- ✅ 文档完整性验证
- ✅ 开发规范检查
- ✅ CI/CD 流水线

### 1.3 风险评估

**严重程度**：中等

**风险**：
- 开发者运行检查脚本时遇到权限错误
- CI/CD 流水线可能因脚本错误而中断
- 检查结果不准确，影响代码质量管理
- 脚本运行缓慢，降低开发效率

## 二、问题分析

### 2.1 根本原因

#### 原因1：未排除特殊目录

```bash
# 问题代码示例
find apex-*/src/main/java -name "*.java" -type f
```

**问题**：
- 会扫描 `.trae` 目录（可能有权限限制）
- 会扫描 `target` 目录（包含大量编译产物）
- 会扫描 `.git` 目录（版本控制元数据）
- 会扫描 `.idea` 目录（IDE配置文件）

#### 原因2：缺少错误处理

```bash
# 问题代码示例
find apex-*/src/main/java -name "*.java" -type f | grep -v "/test/"
```

**问题**：
- 没有重定向 stderr，权限错误会显示在终端
- 没有 `|| true` 容错处理，可能导致脚本中断

#### 原因3：数字格式处理不当

```bash
# 问题代码示例（scan-javadoc-issues.sh:85）
PUBLIC_METHOD_COUNT=$(grep -c "pattern" "$file" 2>/dev/null || echo "0")
if [ "$PUBLIC_METHOD_COUNT" -gt 3 ]; then
```

**问题**：
- `grep -c` 可能返回带换行符的结果
- 变量可能包含非纯数字字符（如 "0\n0"）
- 导致比较运算失败："integer expression expected"

## 三、解决方案

### 3.1 修复策略

#### 策略1：统一排除规则

为所有 `find` 命令添加统一的目录排除规则：

```bash
find <路径> -name "<模式>" -type f \
    -not -path "*/.trae/*" \      # 排除TRAE工具目录
    -not -path "*/target/*" \     # 排除Maven编译输出
    -not -path "*/.git/*" \       # 排除Git仓库目录
    -not -path "*/.idea/*" \      # 排除IDEA配置目录
    2>/dev/null                   # 抑制错误输出
```

#### 策略2：增强错误容错

在关键位置添加容错处理：

```bash
# 方案A：抑制错误并提供默认值
find ... 2>/dev/null || true

# 方案B：在比较运算中添加错误抑制
if [ "$VAR" -gt 3 ] 2>/dev/null; then
```

#### 策略3：规范数字处理

确保所有计数变量都是纯数字：

```bash
# 清理换行符和空白字符
COUNT=$(grep -c "pattern" "$file" 2>/dev/null | tr -d '\n' || echo "0")

# 或使用更严格的提取
COUNT=$(echo "$raw_count" | grep -o "[0-9]*" | head -1)
COUNT=${COUNT:-0}
```
