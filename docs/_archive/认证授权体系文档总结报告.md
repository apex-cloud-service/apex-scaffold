| 9 | 参考图表 | 关联 4 张 SVG 架构图 |

### 2.2 核心技术决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 默认授权模式 | 授权码 + PKCE | 最安全,适合浏览器/移动端 |
| Access Token 格式 | JWT (RS256) | 无状态验证,支持过期检查 |
| Refresh Token 格式 | UUID | 不透明、可轮换、可撤销 |
| PKCE 挑战方法 | S256 (SHA256) | 比 plain 更安全 |
| Token 轮换策略 | 滑动窗口(剩余 <30 分钟触发) | 平衡安全与体验 |
| 黑名单 TTL | 30 分钟 | 覆盖 Access Token 最大有效期 |

### 2.3 关键代码片段

**PKCE 生成**:
```typescript
const codeVerifier = base64urlEncode(randomBytes(32));
const codeChallenge = base64urlEncode(sha256(codeVerifier));
```

**Token 续期判断**:
```java
if (remaining.toMinutes() < 30) {
    // 生成新的 Refresh Token,旧 Token 加入黑名单
}
```

### 3.2 核心技术决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| Keycloak 版本 | 23.0 | 稳定,支持 OIDC 1.0 |
| Client 类型 | confidential | 服务端持有 secret |
| Access Token 有效期 | 5 分钟 | IDP Token 短暂有效,降低泄露风险 |
| 用户同步方式 | keycloak_sub 字段映射 | 唯一标识,支持 LDAP/AD |
| 业务 API Token | Apex JWT(不用 ID Token) | 统一权限体系,解耦 IdP |

### 3.3 关键配置

**Client 配置要点**:
- Valid redirect URIs: `https://api.apex-scaffold.com/login/oauth2/code/keycloak`
- PKCE code challenge method: `S256`
- Direct access grants: `OFF`(禁用密码模式)

**数据库迁移**:
```sql
ALTER TABLE sys_user ADD COLUMN keycloak_sub VARCHAR(255);
ALTER TABLE sys_user ADD UNIQUE KEY uk_keycloak_sub (keycloak_sub);
```

## 6. 技术亮点总结

### 6.1 统一认证架构

**核心设计**: 三种认证方式,一套统一的 JWT Token。

| 认证方式 | 入口路径 | Token 来源 | 权限来源 |
|---------|---------|-----------|---------|
| JWT 本地认证 | `/api/v1/**` | Apex JWT | RBAC 角色 + 数据权限 |
| OAuth2 开放平台 | `/oauth2/api/**` | OAuth2 Token | Scope 权限 |
| Keycloak OIDC | `/oauth2/authorization/keycloak` | Keycloak ID Token → Apex JWT | Keycloak Role → RBAC |

### 6.2 安全机制

| 机制 | 说明 | 涉及文档 |
|------|------|---------|
| PKCE (S256) | 防授权码劫持 | OAuth2, Keycloak |
| Token 轮换 | Refresh Token 一次性使用 | OAuth2, SSO |
| Token 黑名单 | Redis 实现,30 分钟 TTL | OAuth2, SSO |
| HttpOnly Cookie | 防 XSS 窃取 Token | SSO |
| SameSite=Lax | 防 CSRF | SSO |
| Scope 最小权限 | 只授予必要范围 | OAuth2 |
| State 参数 | 防 CSRF 攻击 | OAuth2 |

### 6.3 代码质量

- ✅ 所有 Java 代码基于 WebFlux 响应式(Mono/Flux)
- ✅ 阻塞操作(数据库)调度到 boundedElastic 线程池
- ✅ 前端使用 TypeScript + Axios 拦截器模式
- ✅ 配置通过环境变量注入,无硬编码
