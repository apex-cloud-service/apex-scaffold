# 任务管理（docs/tasks）

本目录是任务治理的唯一入口。

- [任务大盘](./project-tasks.md) — 全量任务、优先级、状态、负责人、验收标准与风险登记

规则要点：
1. 每个任务必须有且只有一个 R0 协调智能体；只有 R0 可写 `project-tasks.md`、合法状态变更、租约和最终集成结果，其余智能体只读。
2. R1 只生成任务卡草案并计算依赖，不直接写任务盘；由 R0 建卡、补租约后再动手。
3. 开工前写全基线 SHA、执行者、独立复核者、写入范围、禁止触碰、并行边界、执行环境和验收命令；一个任务同时只能有一个活跃执行租约。
4. 并行写任务必须写入路径互斥并使用独立 worktree；共享 checkout 同一时刻只允许一个写者，任务盘、记忆台账、总索引、记录索引和共享构建文件默认由 R0 串行维护。
5. 执行者完成后提交标准交接包；R2 与 R5 不得是同一智能体实例或会话。R0 逐个集成，禁止先写者胜、强推或硬重置。
6. 任务关闭需具备 R5 结论、集成 commit、治理校验、`docs/records/` 记录及索引和记忆台账；关闭动作只能由该任务 R0 执行，多个任务共享 `dev` 时须遵守全局集成租约。
